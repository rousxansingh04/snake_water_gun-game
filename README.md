# Snake Water Gun

A small browser game based on the classic Snake, Water, Gun game. Pick a move, see what the computer picks, and try to get the higher score.

## Play

Open [`index.html`](index.html) in a browser and click Snake, Water, or Gun. No install or build step is needed.

You can also run it with VS Code's Live Server extension if you prefer using a local server.

## Rules

- Snake beats Water
- Water beats Gun
- Gun beats Snake
- Matching moves are a draw

The scores stay on the page while you play. Use **Reset Game** to start over.

## Built with

- HTML
- CSS
- JavaScript

## Project files

- `index.html` — game layout
- `style.css` — page styling and mobile layout
- `script.js` — game choices, results, and score updates
